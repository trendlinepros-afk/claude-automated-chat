Add a Claude Desktop computer

1. Install Node.js

Install Node.js LTS on the dev PC (provides npx).

2. Trust this relay's certificate (one time per PC)

Run this in PowerShell on the dev PC. It downloads the relay's public certificate and prints its fingerprint — it must match . If it doesn't, delete the file and don't continue.
